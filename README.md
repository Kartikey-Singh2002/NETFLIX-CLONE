# Netflix Clone

A responsive Netflix-inspired streaming website built using **HTML and CSS**. This project recreates the look and feel of the Netflix India homepage with a modern and responsive user interface.

## 🚀 Features

* Netflix-inspired homepage design
* Responsive layout
* Navigation bar with Netflix logo
* Hero section with call-to-action
* Trending movies section
* Movie/show image cards
* FAQ section
* Responsive design for different screen sizes
* Clean HTML and CSS structure

## 🛠️ Technologies Used

* HTML5
* CSS3
* Git
* GitHub

## ▶️ How to Run

1. Clone this repository:

```bash
git clone https://github.com/Kartikey-Singh2002/NETFLIX-CLONE.git
```

2. Open the project folder in VS Code.

3. Open `netflix.html` in your browser.

You can also use the **Live Server** extension in VS Code for a better development experience.
